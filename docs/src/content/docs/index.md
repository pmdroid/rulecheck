---
title: Rulecheck
description: Deterministic repository checks with TypeScript rule files.
---

Write a TypeScript rule with a clear fix and an example of what should pass and fail. Rulecheck reads it as data and reports violations by file, line, and rule ID.

[Install the CLI](./quickstart/) to run checks. Use [the npm SDK](https://www.npmjs.com/package/@pmdroid/rulecheck) for TypeScript editor types when writing rules. Use the Rule cookbook to pick the simplest check that fits your repository. Use an existing linter or test when it already expresses the rule.
